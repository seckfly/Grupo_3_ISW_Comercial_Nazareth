# Matriz fase-artefacto

La matriz indica el nivel de madurez previsto para cada artefacto en las cuatro fases RUP. Los estados describen el ciclo de elaboración del artefacto; no indican que los entregables de las fases futuras ya estén producidos.

**Estados:** Borrador (primera versión), Base (acordado), Refinado (mejorado), Final (entregado), — (no aplica en esa fase).

| SRS breve | Borrador | Base | Refinado | Final |

El diagrama de actividad de CU01 se modela desde Inicio porque la venta relaciona el importe cobrado y el inventario. La etiqueta v1.0-iter1 identifica la línea base de ITER-1; no corresponde a la fase de Transición. La versión de entrega se identificará al completar esa fase.
