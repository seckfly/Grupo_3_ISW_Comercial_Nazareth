# Glosario

| Término | Significado |
|---|---|
| Venta | Operación que registra productos, cantidades, importes y método de pago. |
| Detalle de venta | Líneas de productos, cantidades, precio unitario y subtotal asociados a una venta. |
| Stock | Cantidad registrada disponible de un producto. |
| Umbral mínimo | Cantidad de referencia para alertar que un producto requiere revisión de existencias. |
| Alerta de stock | Aviso para productos activos cuyo stock es menor o igual al umbral mínimo. |
| Movimiento de inventario | Registro de una entrada, salida o ajuste de existencias. |
| Cliente registrado | Cliente con cuenta en el portal. |
| Solicitud de separación | Solicitud para separar productos; no equivale a una venta ni bloquea stock en el prototipo. |
| Orden de compra | Registro de productos, cantidades, costos y datos del proveedor para una compra. |
| Recepción de mercadería | Registro de las cantidades recibidas de una orden pendiente. |
| Proveedor | Persona o empresa que abastece al negocio y se coordina con Humberto fuera de la aplicación. |
| Promoción | Campaña aplicada a un producto durante una vigencia definida. |
| Método de pago | Forma registrada para una venta: efectivo, Yape o Plin. |
| Perfil administrativo | Acceso interno que reúne las funciones de Humberto como Vendedor, Administrador, Responsable de almacén y Responsable de compras. |
| Portal de clientes | Interfaz para consultar catálogo, promociones, cuenta, historial y beneficios. |
