# Glosario

| Término oficial | Significado en el proyecto |
|---|---|
| Venta | Operación que registra productos, cantidades, importe y método de pago |
| Stock | Cantidad registrada disponible de un producto |
| Cliente registrado | Cliente que tiene una cuenta en el portal |
| Solicitud de separación | Solicitud para separar productos; no implica que el stock quede bloqueado |
| Orden de compra | Registro de una compra a proveedor, especificado en CU08 |
| Recepción de mercadería | Registro de lo recibido de una orden de compra, especificado en CU09 |
| Movimiento de inventario | Registro de una entrada o salida de existencias |
| Perfil administrativo | Perfil usado por Humberto para las funciones internas |
| Portal de clientes | Interfaz para consultar catálogo, promociones y datos de la cuenta |

Los nombres de los casos de uso se mantienen como aparecen en el informe actualizado.
