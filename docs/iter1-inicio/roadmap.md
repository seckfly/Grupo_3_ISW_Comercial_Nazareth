## Criterios de trabajo

- CU01 es el proceso crítico porque relaciona el cobro, el detalle de venta y el movimiento de inventario.
- Los diagramas se limitan a los necesarios para explicar el sistema y analizar ese proceso.
- El tablero de Trello organiza las fases por estado de avance y mantiene una lista separada de riesgos.
- Los cinco riesgos se revisan durante el trabajo de las iteraciones.
- La revisión de ITER-1 quedó registrada como revisión individual.

La etiqueta v1.0-iter1 identifica la línea base de Inicio. No representa la finalización de las fases posteriores.
